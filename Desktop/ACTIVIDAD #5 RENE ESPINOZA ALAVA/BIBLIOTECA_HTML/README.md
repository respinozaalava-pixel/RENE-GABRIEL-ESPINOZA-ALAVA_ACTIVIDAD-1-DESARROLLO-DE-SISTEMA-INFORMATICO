## 🎯 Objetivo
Diseñar y desarrollar una biblioteca de componentes de interfaz de usuario reutilizables mediante CSS3, para establecer la línea gráfica oficial del Sistema de Gestión de Incidentes (Help Desk). Se aplican variables CSS, modelo de cajas, selectores avanzados y estados de interacción.
